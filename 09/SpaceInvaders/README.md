# SpaceInvaders

A simplified Space Invaders style game written in Jack for nand2tetris Project 9.

Controls:

- Left arrow: move left
- Right arrow: move right
- Space: fire
- Q or ESC: quit

Load this directory in the VM Emulator after compiling it with the Jack compiler. Use the built-in OS when the emulator asks, and set animation to "No animation" for smoother play.
